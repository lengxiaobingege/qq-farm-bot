# 图鉴、变异宝典与藏品

> **适用版本**：`1.16.3.8_20261028`（2026-11-01 起，2026-11-02 复核）
> **样本**：2026-11-01 官方包 + 同日抓包；11-02/11-03 实机操作
> **现状**：仍有效。藏品操作仅支持激活/升星/领奖/展示，许愿与切换展台未开放

图鉴从个人页移出，成为独立侧栏入口 `/illustrated`，含四个分区：作物图鉴、超变图鉴、藏品（珍藏室）、变异宝典。手机侧栏同菜单。

## 一、藏品协议

读取：`gamepb.collectionpb.CollectionService.GetCollections`，蓝晶类别 `item_type=1`。请求/响应字段与字节已和官方编码器及抓包核对；**服务端没返回类别时保留错误状态**，不要显示成空收藏。

| 操作 | 协议 | 关键字段 |
| --- | --- | --- |
| 激活 / 升星 | `UpgradeCollection` | 分类 1 + 藏品 ID；首次=激活，重复=升星 |
| 领评分奖励 | `ClaimCollectionReward` | 一次可同时领多档，状态以回包为准 |
| 展示 / 取消 | `SwitchSceneDisplay` | `display_slot` 是 **field 1**，藏品用 slot 1；`item_id=0` 取消，换藏品即替换原展示 |

后台读取视图展示：系列、星级、重复持有数、展示状态、许愿状态、评分、各奖励档位、激活/下一星所需材料。

判定口径：

- **拥有副本 ≠ 已激活**
- 当前评分用服务端返回值；**已生效增益以 `claimed_reward_score` 为准**，未领取的档位不能提前算进增益
- 结果未知（超时、解析失败）**不要自动重发**，重新读状态再决定

实机样本（2026-11-02/03）：

| 藏品 | 来源 | 结果 |
| --- | --- | --- |
| 桃米 700005 | 钻石礼包 | 激活 → 1 星、总评分 600；下一星需重复藏品 2 份 + 金币 3,000,000；400 分奖励已领，加成「1% 概率节省 10% 肥料」 |
| 棉芽 700001 | 金豆豆礼包（果冻花园 2002，稀有） | 激活 → 1 星、重复持有 1→0、总评分 600→1200；1000 分档位已领 |
| 布丁 | 50 连开金豆豆礼包 | 与棉芽各 1 个，两次激活各耗 1 副本，评分 600 → 1200 |

## 二、藏品变异识别

`MutantEffect`：藏品变异为 **18**、奶茶为 **17**，但两者图标配置都指向 `naicha`——所以土地卡片**不能**用 18 的奶茶占位图。

补齐的字段：

| 位置 | 字段 | 说明 |
| --- | --- | --- |
| `MutantInfo` | `collection_series_id`（field 7） | 藏品系列 |
| `MutantInfo` | `collection_item_id`（field 8） | 具体藏品 |
| `PlantInfo` | field 41 | 变异记录，沿用 `extended_mutations` 名 |

土地读取视图在 `mutantEffects` 的藏品项里加 `collections`（按系列 + 物品 ID 去重，给出名称与已有图片）。**只收到变异 18、没有具体 ID 时用通用藏品图标**，不猜是哪款，也不能把变异标记当成已入库或已激活。

规则要点：

- 只有**蓝晶土地**参与藏品变异
- 各档位保底进度**独立累计**，不能把全农场或跨档位收获次数合并
- 稀有 / 珍品 / 天工公开概率均 3.33%，对应保底 40 次
- 日常农场有「自动收获天工作物」开关（默认开，兼容旧账号）；关掉后自动巡田与施肥后的收获跳过天工，手动一键收获不受影响
- 游戏客户端本地开关是 `settings_one_click_tg`，**不属于 `UserSettings` 服务端字段**，助手不要伪造同名设置

## 三、概率与保底

概率取 `CollectionGroup.public_probability / 100`，按官方界面保留一位小数；保底取 `display_guarantee`。

普通系列示例（4 / 8 / 12 / 24 小时）：展示概率 1.2% / 2.3% / 3.3% / 6.5%，保底 120 / 60 / 40 / 20 次。

> 这是**系列变异概率**，不是单款藏品概率。写文案时别混。

变异宝典分常规 / 装扮 / 藏品三类，读官方变异配置、概率公示与系列资料，**不需要运行账号**。隐藏事件不进普通变异展示；宝典按官方 `display` 规则筛系列，珍藏室保留完整五系列 30 款。系列问号支持悬停与点击固定说明（键盘聚焦、手机点击同样可用）。

## 四、实现位置

`core/src/services/collections.ts`：

- `getCollectionsSnapshot()` —— 读藏品状态
- `operateCollections()` —— 激活/升星/领奖/展示，复用账号 Worker，同账号写操作串行；每次写入前重读状态与余额，重叠读取合并
- `getMutationCatalog()` —— 本地变异宝典

## 五、验证边界

- 真实账号数据不作测试输入，回归在忽略目录的独立工作区跑
- 浏览器预览只用模拟账号与只读接口；切换/停止账号或离开页面时旧请求结果失效
- 抓包、解包产物、预览截图不进发布内容
- 本轮后端回归 36 项、前端 64 项通过；核心与客户端编译、类型检查、构建、lint 通过；人工核对分类/筛选/搜索/详情/评分奖励/说明浮层/深色主题与 320·390 px 布局
